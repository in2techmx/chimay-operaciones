## 🛠️ Características Principales
1. **Diagrama de Gantt Interactivo**: Escalas diaria, semanal y mensual impulsadas por Frappe Gantt SVG.
2. **Tablero de Tarjetas / Vista Móvil**: Visualización amigable para smartphones en campo.
3. **Filtro Rápido por Responsable**: Visualización de la carga de trabajo de cada miembro del equipo.
4. **Desglose Tripartito de Costos**: Personal/Mano de Obra, Materiales/Insumos y Servicios de Terceros.
5. **Sincronización Bidireccional**: Conexión vía API Web App de Google Apps Script (`doGet` / `doPost`) para actualización en tiempo real con Google Sheets y Google Tasks.
